# Daily Highs/Lows

## Overview

This indicator plots current day high/low and previous day highs/lows. It can be cumbersome to mark out daily highs/lows when checking for daily swing points and closures every day. This indicator simplifies that process by marking these levels out automatically. All levels can be seen on the daily timeframe and lower timeframes.

## Concepts

- Adds PDH/PDL lines/labels to point out Previous Day High and Previous Day Low
- Adds PDHn/PDLn lines/labels where n is a number denoting extra previous days (e.g., PDH1, PDL1 denoting Previous Day High/Low 1 day before PDH/PDL.
