# Changelog

All notable changes to this indicator are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/) and match `SCRIPT_VERSION` in `mod.pine`.

## [0.0.1] - 2026-08-03

### Added

- Bullish (L, H, LL, HH) and bearish (H, L, HH, LL) breaker formations with BRKR +/- boxes.
- Separate swing length, confirmation type (candle close or candle wick) and box color for bullish and bearish setups.
- "Show Setups" and "Breaker History" inputs.
